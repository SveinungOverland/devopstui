# DevOPS TUI

DevOPS TUI is a small TUI written in Golang that allows for easy management of Azure Devops

# Features

- Quickly change between boards and sprints
- See hierarchy of Epic/Features/PBIs
- Quickly edit Epics/Features/PBIs
- Quickly move Features/PBIs
- Util stuff like selecting multiple items for moving, for example when moving features from one sprint to the next
- Dashboard view with featured items belonging to the user
